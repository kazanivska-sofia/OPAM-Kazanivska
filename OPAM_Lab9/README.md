# Лабораторна робота №9. Реалізація та порівняння алгоритмів сортування

**Варіант:** N=11, K=22 (a=2, b=3, c=1)

---

## 1. Завдання 1: Тресування сортування бульбашкою вручну
Масив з 9 елементів: `[11, 4, 18, 2, 9, 20, 5, 11, 1]`

- **Прохід 1:** Порівнянь = 8, Обмінів = 6. Найбільший елемент `20` перемістився в кінець.
- **Прохід 2:** Порівнянь = 7, Обмінів = 5.
- **...**
- **Разом:** Порівнянь $\approx 36$, Переставлянь $\approx 54$.

---

## 2. Пояснення до Завдання 4 (Властивості чисел у 12 клітинках)

- **Бульбашкове сортування з прапорцем:**  
  На вже відсортованому масиві робить рівно $N-1$ порівнянь і $0$ переставлянь, завдяки чому миттєво зупиняється на першому ж проході.
- **Швидке сортування (QuickSort з медіаною трьох):**  
  Завдяки вибору медіани з 3 елементів, навіть на вже відсортованому або зворотному масиві опорний елемент ділить масив навпіл. Кількість порівнянь залишається $O(N \log N)$ замість деградації до $O(N^2)$.
- **Сортування вставками з бінарним пошуком:**  
  Бінарний пошук зменшує кількість порівнянь до $O(N \log N)$, але кількість фізичних зсувів/переставлянь елементів у масиві залишається $O(N^2)$. Тому загальний час сортування практично не зменшується.

## 4. Відповіді на висновки (Завдання 6)

1. **Відношення порівнянь простого й швидкого алгоритму при $n = 1000$:**  
   Для бульбашкового сортування порівнянь $N^2 / 2 \approx 500\,000$. Для QuickSort: $N \log_2 N \approx 1000 \times 10 = 10\,000$. Відношення складає близько **50 разів**.
2. **Чому `Array.Sort` швидший за власний $N \log N$:**  
   `Array.Sort` використовує `IntroSort` (гібрид QuickSort, HeapSort та InsertionSort), написаний на низькорівневому C++ з прямою оптимізацією команд процесора та розгортанням циклів без додаткових викликів делегатів `Func<T, T, int>`.
3. **100 000 записів із ключем 0..300 (обов'язкова стабільність):**  
   Для цієї задачі найкраще обрати **Сортування підрахунком (Counting Sort)** або **Bucket Sort**. Вони працюють за $O(N)$ часу і є абсолютними лідерами для вузького діапазону цілих чисел.

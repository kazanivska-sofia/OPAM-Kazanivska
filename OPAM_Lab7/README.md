**Варіант:** N=11, K=22 (a=2, b=3, c=1)

## 1. Параметри Filter між трьома застосуваннями
Скільки разів змінювали тіло `Filter` між трьома застосуваннями: **0 (нуль)**. Алгоритм є універсальним (узагальненим за типом `T`), а вся спеціалізована логіка передається через лямбда-вирази в параметр `keep`.

---

## 2. Шпаргалка для чотирьох агрегацій (Завдання 3)

1. **Сума:**
   * **Стан:** `int` (поточна сума)
   * **Старт:** `0`
   * **Крок:** `(acc, x) => acc + x`
2. **Добуток:**
   * **Стан:** `long` (поточний добуток)
   * **Старт:** `1L`
   * **Крок:** `(acc, x) => acc * x`
3. **Максимум:**
   * **Стан:** `int` (поточне максимальне значення)
   * **Старт:** `numbers[0]` (перший елемент списку)
   * **Крок:** `(acc, x) => Math.Max(acc, x)`
4. **Найбільший за абсолютною величиною елемент (c = 1):**
   * **Стан:** `int` (елемент із найбільшим значенням `Math.Abs`)
   * **Старт:** `numbers[0]`
   * **Крок:** `(acc, x) => Math.Abs(x) > Math.Abs(acc) ? x : acc`

## 3. Пояснення трьох несподіванок захоплення змінних (Завдання 5)

1. **Змінна після лямбди:**  
   Лямбда-вираз захоплює не поточне *значення* змінної, а *посилання* на змінну. Оскільки значення `threshold` було змінено на 1000 до виклику лямбди, функція використала нове значення.
2. **Лічильник циклу for:**  
   Змінна `i` оголошується один раз на весь цикл. Усі 3 лямбди захопили посилання на одну й ту саму змінну `i`. На момент їх виклику цикл завершився, і `i` дорівнювала 3.
3. **Цикл foreach:**  
   Починаючи з C# 5.0, у циклі `foreach` змінна ітерації перестворюється на кожному кроці циклу, тому кожна лямбда захоплює свою власну копію змінної.
* **Як виправити пункт 2:** Створити локальну змінну всередині циклу `for`: `int temp = i; funcsFor.Add(() => temp);`.

## 4. Висновок (Завдання 6)

1. **Порівняння з Лабораторною 4:** У ЛР4 для 3 критеріїв і 3 типів даних довелося б написати $3 \times 3 = 9$ окремих функцій. У ЛР7 написано всього **1 узагальнену функцію `Filter<T>`**.
2. **Приклад, де узагальнення було б зайвим:** Якщо функція виконує специфічну бізнес-логіку, що прив'язана виключно до одного класу (наприклад, розрахунок стипендії конкретно для `Student`), узагальнення створить зайву складність без жодної користі.
